# Modelos para validação

Estes ficheiros são modelos ainda sem resultados de uso real. A base documental não comprova procura ou desempenho do produto.

- [Roteiro de entrevistas](ROTEIRO_DE_ENTREVISTAS.md): pesquisa com casais, convidados e profissionais; mensagens são rascunhos para envio autorizado pelos fundadores.
- [Registo de validação](REGISTRO_DE_VALIDACAO.md): hipóteses, resultados e horas/quotas da operação.

Não substituir a tabela de hipóteses por resultados presumidos. Para resultados, registar data, versão/cenário, método, evidência, conclusão e limite. Manter o modelo reutilizável e guardar notas anónimas por pesquisa no local privado escolhido pelos fundadores; contactos, consentimentos e listas de convidados nunca entram nos documentos públicos.

Tarefas de teste funcional só se aplicam quando houver produto/demonstração correspondente. Enquanto existir apenas a landing, avaliar compreensão, navegação e interesse sem fingir criação/publicação/RSVP reais.
